# pin-pok

Подсказки к столу Lucky Chip Hold'em на Pinco. Карты читает локальный Python
(Pillow + OpenCV), банк и стеки берутся из HTML. Виджет открывается отдельным
окном, его можно убрать с стола.

Подсказка за живым столом обычно против правил комнаты. Можно словить бан.

## Запуск

Windows: двойной щелчок по `start.bat`. Окно не закрывать, в нём сервер зрения.
Первый раз он сам поставит зависимости.

Потом в Chrome:

1. `chrome://extensions`, режим разработчика
2. «Загрузить распакованное» — папка `extension`, не корень проекта
3. На странице игры F5 и клик по иконке расширения

Если сервер уже был запущен, скрипт второй не поднимает.

Проверка: `curl http://127.0.0.1:8765/health`

Linux / macOS:

```bash
python3 -m pip install -r requirements.txt
./start-vision.sh
python3 tools/pack_extension.py
```

В Chrome грузить получившуюся папку `extension/`.

## Если пустые карты

Сервер должен отвечать на `/health`, в виджете источник `py`. Стол целиком в окне,
DevTools не поверх карт. После правки файлов — «Обновить» у расширения и F5.

Chrome не грузит расширение, если в папке есть имя на `_` (обычно `__pycache__`).
`npm run preflight` показывает, что мешает. `start.bat` байткод рядом с исходниками не пишет.

## Как считается совет

Префлоп — чарты по позиции. Постфлоп — эквити против диапазона и пот-оддсы.
Если карты прочитались не полностью, остаётся Монте-Карло.

Фишки дилера в HTML нет, позиция оценивается по размеру банка и ставки.
Чарты — обычный 6-max, не выгрузка солвера. Скриншоты уходят только на `127.0.0.1:8765`.

Тесты: `npm test`.
